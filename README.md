# USGA GHIN Handicap Index Calculator

This project is a React + TypeScript + Vite app that will calculate and display a user’s USGA GHIN handicap index. It uses Material UI and stores data locally (IndexedDB).

## Scripts

- `npm run dev` – start dev server
- `npm run test` – run unit tests with coverage
- `npm run lint` – run ESLint
- `npm run format` – format with Prettier
- `npm run build` – typecheck and build
- `npm run preview` – preview production build

## Stack

- React, TypeScript, Vite
- Material UI (MUI v5), React Router, React Query
- Dexie (IndexedDB), React Hook Form, Zod, Zustand
- Vitest + Testing Library
